# 系统架构设计

## 1. 项目概述

基于 Go 语言的商品库存与秒杀系统，采用渐进式微服务架构：第一阶段以单体模块化快速实现基础功能，第二阶段容器化部署并通过 Nginx 实现负载均衡与动静分离，第三阶段引入分布式缓存，后续进行微服务架构拆分。

## 2. 服务拆分

系统按业务领域拆分为四个核心服务模块：

| 服务                     | 职责               | 核心能力                              |
| ------------------------ | ------------------ | ------------------------------------- |
| **用户服务 (User)**      | 用户认证与信息管理 | 注册、登录、JWT 签发、用户资料 CRUD   |
| **商品服务 (Product)**   | 商品目录管理       | 商品 CRUD、分页查询、上下架状态管理   |
| **库存服务 (Inventory)** | 库存管控           | 库存设置、乐观锁扣减、库存归还        |
| **订单服务 (Order)**     | 订单全生命周期     | 下单（Saga 模式）、订单查询、取消退库 |

## 4. 模块内部分层架构

每个业务模块内部均遵循统一的三层结构：

```
┌─────────────────────────────────┐
│  Handler 层（HTTP 路由处理）      │  ← 接收请求、参数校验、调用 Service
├─────────────────────────────────┤
│  Service 层（业务逻辑）           │  ← 核心逻辑、事务编排、跨模块调用
├─────────────────────────────────┤
│  Repository 层（数据访问）        │  ← GORM 数据库操作、SQL 查询
└─────────────────────────────────┘
                │
                ▼
          PostgreSQL
```

**设计原则：**

- 模块间**只通过 Service 层接口调用**，不直接访问其他模块的 Repository
- 统一响应格式：`{ code, message, data }`
- 统一错误处理：使用类型化哨兵错误（如 `ErrUserExists`、`ErrStockInsufficient`）

## 5. 项目目录结构

```
flash-sale/
├── cmd/server/
│   └── main.go                  # 入口，模块装配，启动 HTTP 服务
├── internal/
│   ├── user/                    # 用户模块
│   │   ├── model.go             # 数据模型
│   │   ├── handler.go           # HTTP 路由处理
│   │   ├── service.go           # 业务逻辑（注册、登录、JWT）
│   │   └── repository.go        # 数据库操作
│   ├── product/                 # 商品模块（同结构）
│   ├── inventory/               # 库存模块（同结构）
│   ├── order/                   # 订单模块（同结构）
│   └── middleware/
│       └── auth.go              # JWT 认证 + Admin 权限中间件
├── pkg/
│   ├── config/config.go         # Viper 配置加载
│   ├── database/postgres.go     # GORM 数据库连接
│   └── response/response.go     # 统一 JSON 响应格式
├── config/
│   └── config.yaml              # 应用配置文件
├── web/                         # 前端静态文件
│   ├── index.html
│   ├── css/style.css
│   └── js/app.js
├── nginx/                       # Nginx 配置（多种负载均衡算法）
│   ├── nginx.conf               # 默认轮询
│   ├── nginx-weighted.conf      # 加权轮询
│   └── nginx-iphash.conf        # IP Hash
├── Dockerfile                   # 多阶段构建
├── docker-compose.yaml          # 生产部署编排
├── docker-compose.dev.yaml      # 开发环境（仅 PostgreSQL）
├── Makefile                     # 常用开发命令
├── go.mod
└── go.sum
```
